Add to Home Screen

Your membership is ready. Install the mini app first, then open it from your Home Screen to enter the dashboard.

Mobile browser access stays locked until the app is opened from the Home Screen.

iPhone / iPad

1. Tap the button above.
2. In the iPhone menu, choose Add to Home Screen.
3. Tap Add.
4. Open the new San Sebastian icon from your Home Screen.

If “Add to Home Screen” is not shown, tap Safari’s Share button manually and scroll down to Add to Home Screen.

Android

Tap the button above. If Chrome supports the install prompt, it will open directly. Otherwise use the browser menu and choose Install app or Add to Home screen.
