Install Mini App

Add the club to your Home Screen for the best experience.

iPhone / iPad

1. Tap the button above.
2. In the Share menu choose Add to Home Screen / Zum Home-Bildschirm.
3. Tap Add / Hinzufügen.
4. Open the San Sebastian icon from the Home Screen.

Android

Tap the button. If the install prompt is available it opens directly. Otherwise use the browser menu and choose Install app or Add to Home screen.
